# Math Rhythm Web Game (เกมจังหวะดนตรีคำนวณเลข 1 หลัก)

เกมแนวจังหวะเพลง (Rhythm Game) ผสมผสานการคิดเลขเร็วเลข 1 หลัก (ผลลัพธ์ 0 - 9) ตามจังหวะบีทของดนตรี พัฒนาด้วย HTML5, CSS3 และ JavaScript (Web Audio API)

---

## ฟีเจอร์หลัก (Features)

1. **หน้าเมนูหลัก (Main Menu):**
   - ปุ่มเริ่มเล่นเกม (Play) นำไปสู่หน้าเลือกเพลง
   - ปุ่มตั้งค่าเสียง (Settings) - สี `#EEEEEE`
   - ปุ่ม Edit สร้างชาร์ต/อัปโหลด MP3 - สี `#2F39A9`
   - ปุ่มออกจากเกม (Exit) - สี `#A82020`
   - แถบสถานะผู้ใช้และปุ่มสมัคร/เข้าสู่ระบบ

2. **ระบบสมาชิกและเข้าสู่ระบบ (Authentication):**
   - การสมัคร: กรอกชื่อ User, รหัสผ่าน และยืนยันรหัสอีกรอบ
   - การเข้าสู่ระบบ: กรอกชื่อ User และรหัสผ่าน
   - มีระบบแจ้งเตือนกรณีรหัสผ่านหรือชื่อผิด: **"คุณกรอกรหัสผิดหรือชื่อ user ผิด"**

3. **หน้าตั้งค่าระบบเสียง (Audio Settings):**
   - ปรับระดับความดังเพลง (BGM Volume)
   - ปรับระดับความดังเสียง UI / เสียงเอฟเฟกต์ (SFX Volume)
   - สวิตช์ปิดเสียงทั้งหมด (Mute Toggle)

4. **หน้าเลือกเพลงและลีดเดอร์บอร์ด (Song Select & Leaderboard):**
   - ปุ่มเลือกเพลงสี `#0D47A1`
   - กระดานลีดเดอร์บอร์ดสี `#2196F3`
   - มีเพลงพร้อมเล่นในตัว (Tutorial, Electro Rush, Cyber Pulse)
   - แสดงคะแนนสูงสุด (Rank, ผู้เล่น, คะแนน, สถิติ Perfect/Great/Miss, วันที่) แยกเฉพาะตามแต่ละเพลง

5. **ระบบ Edit เพลง (Song & Chart Editor):**
   - อัปโหลดไฟล์เพลง MP3 (และ WAV/OGG)
   - กำหนดความเร็วของจังหวะ (โน้ตวิ่งมาจากข้างหน้ากี่วินาที - Approach Time)
   - เพิ่มโน้ตโจทย์เลข 1 หลัก (คำตอบ 0 - 9) พร้อมระบบตรวจสอบอัตโนมัติ
   - โหมดเคาะบีทตามเพลง (Tap to Beat) บันทึกจังหวะแบบ Real-time
   - บันทึกเข้าคลังเพลง Custom และเล่นได้ทันที

6. **ระบบการเล่นเกม (Gameplay):**
   - ลู่วิ่งโน้ตมุมมองมิติ 3D พร้อมแถบเป้าหมาย HIT ZONE
   - แป้นกดตัวเลขบนหน้าจอสี `#15D8B3` (รองรับทั้งการคลิก/ทัชสกรีน และการกดคีย์บอร์ด 0-9 / Numpad 0-9)
   - สีตัวเลขและเครื่องหมายในโจทย์:
     - 1: เขียวอ่อน (`#81C784`), 2: เขียว (`#4CAF50`), 3: เขียวเข้ม (`#2E7D32`)
     - 4: ชมพูอ่อน (`#F48FB1`), 5: ชมพู (`#E91E63`), 6: ชมพูเข้ม (`#C2185B`)
     - 7: ม่วงอ่อน (`#CE93D8`), 8: ม่วง (`#9C27B0`), 9: ม่วงเข้ม (`#6A1B9A`)
     - 0: โทนฟ้าคราม (`#00BCD4`)
     - เครื่องหมายลบ (`-`): สีแดงเลือดหมู (`#800000`)
     - เครื่องหมายบวก (`+`): สีเขียวโทนเหลือง (`#9ACD32`)
   - ระบบการตัดสิน:
     - **PERFECT**: สีฟ้า (`#00E5FF`)
     - **GREAT**: สีเขียว (`#00E676`)
     - **MISS**: สีแดง (`#FF1744`)

7. **หน้าผลลัพธ์และสรุปคะแนน (Result Scoreboard):**
   - สรุปผลหลังเล่นจบเพลง:
     - กดพลาด (Miss): สีแดง
     - กด Perfect: สีฟ้า
     - กด Great: สีเขียว
     - รวมกด Perfect + Great: สีเขียวอ่อน (`#69F0AE`)
   - อัปโหลดคะแนนไปยัง Leaderboard ของเพลงนั้นๆ ให้อัตโนมัติทันที
   - ปุ่มกดเล่นอีกรอบ (Replay): สีเหลืองโทนเขียว (`#D4E157`)
   - ปุ่มกลับหน้าเลือกเพลง: สีเทา (`#757575`)
   - ตัวอักษรสีขาวกรอบดำบางคมชัด พื้นหลังหลักสี `#E3F2FD`

## วิธีเปิดเล่นเกม (How to Run)

### วิธีที่ 1: เปิดผ่านเบราว์เซอร์โดยตรง (Direct Browser)
- ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดเล่นผ่าน Google Chrome, Microsoft Edge, Firefox หรือเบราว์เซอร์ใดก็ได้

### วิธีที่ 2: รันผ่าน Local Web Server (PowerShell)
เปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
ระบบจะเปิดเว็บเบราว์เซอร์ไปที่ `http://localhost:8080/` โดยอัตโนมัติ
